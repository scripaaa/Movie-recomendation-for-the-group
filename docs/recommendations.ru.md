# Персональные и общие рекомендации

`MovieRecommendations` — отдельный сервис. Контроллер передаёт текущего пользователя и пожелания, получает до 12 результатов: данные фильма, внутренний балл и объяснение.

## Алгоритм

1. Для каждого жанра оценённых фильмов вычисляется среднее `(оценка - 5.5) / 4.5`. Высокие оценки дают положительный вес, низкие — отрицательный. В персональном подборе используются только оценки текущего пользователя. В общем подборе сначала вычисляются предпочтения каждого участника, затем они усредняются с равным весом на человека: большое число оценок не даёт одному участнику большего влияния. Неизвестные предпочтения считаются нейтральными. Оценки пользователей вне комнаты не участвуют.
2. Из TMDB Discover загружаются две страницы популярных кандидатов. При наличии предпочтений и отсутствии явно выбранного жанра добавляется страница по трём любимым жанрам. Повторы удаляются.
3. Пожелания по жанру и длительности передаются в TMDB. Для ограничения длительности также требуется положительный хронометраж; фильмы с неизвестной длительностью исключаются API. Минимальное число голосов — 50.
4. По умолчанию исключаются фильмы, оценённые пользователем, а в комнате — хотя бы одним участником. Здесь «просмотренный» означает «имеющий оценку»; отдельного списка просмотров пока нет.
5. Соответствие вкусу — средний вес жанров кандидата. Общедоступная оценка сглаживается к 5 с весом 100 голосов: `(rating * votes + 5 * 100) / (votes + 100)`.
6. Итоговый балл: `2 * соответствие + сглаженная_оценка / 10`. При равенстве используются число голосов и TMDB ID. Это эвристический балл, а не вероятность того, что фильм понравится.

В комнате к усреднённым жанровым предпочтениям прибавляются отрицательные поправки `rooms.quiz_genre_weights`, накопленные от ответов «Нет» в квизе. В персональном подборе эти поправки не используются. Внутри квиза исходные кандидаты пересортировываются с учётом новых отказов; история личных оценок не меняется. Подробности — в [правилах квиза](quiz.ru.md).

Без оценок или известных жанров используется общий рейтинг кандидатов. Разнообразие обеспечивается общим пулом популярных фильмов наряду с пулом любимых жанров; отдельного ограничения на число фильмов одного жанра пока нет.

## Хранение жанров

`movies.genre_ids` — JSON-массив идентификаторов жанров TMDB. При первой оценке заполняется из ответа TMDB Details. `nil` означает, что сведения ещё не загружены, `[]` — что жанры отсутствуют.

Для фильмов, оценённых до миграции, сервис догружает жанры максимум пяти фильмов за запрос и сохраняет их. При большом старом каталоге профиль уточняется постепенно. В случае ошибки TMDB экран показывает сообщение с предложением повторить запрос.

## Границы первой версии

Персональный подбор вызывает `MovieRecommendations.new(user: ...)`, общий — `MovieRecommendations.new(users: room.members)`. Общая подборка запускается POST-запросом участника и сохраняется вместе с фильтрами в комнате. GET показывает сохранённый результат всем участникам без повторных запросов TMDB. Новые оценки и участники учитываются после повторного запуска; при ошибке API предыдущий результат сохраняется.

Нет машинного обучения, поиска похожих пользователей или ранжирования всего каталога: сервис выбирает из ограниченного пула TMDB. Для работы нужен настроенный `TMDB_API_READ_ACCESS_TOKEN`.

Проверка: `ruby bin/rails test`. Тесты используют подставной каталог и не требуют сети или токена.

Параметры API: https://developer.themoviedb.org/reference/discover-movie
